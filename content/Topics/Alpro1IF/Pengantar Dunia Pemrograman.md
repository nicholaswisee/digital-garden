## Definisi
- **Definisi Pemrograman** = Proses formulasi persoalan komputasi ke program. Pemrograman bukan cuma coding, tapi analisis persoalan, implementasi, testing, dan debugging.
- **Definisi Paradigma** = POV dari penyelesaian persoalan (dengan program). Setiap persoalan ada pendekatan khusus dalam pemecahannya, nah paradigma tuh ngasih strategi analsiis khusus lah untuk pemecahan masalahnya.

Keep in mind, **Belajar Pemrograman != Belajar Bahasa Pemrograman**, **Belajar Pemrograman** itu belajar **Pola Pikir Komputasional + Paradigma Pemrograman**

## Taksonomi Bahasa Pemrograman
Di dalam bahasa pemrograman, itu ada semacam tingkatannya, dari low-level languages sampai high-level languages. Simplenya, semakin tinggi level bahasanya, maka semakin mendekati manusia. Maksudnya mendekati manusia adalah kasarnya manusia semakin ngerti lah bahasanya. Nah kalo low-level languages tuh makin deket sama apa yang mesin ngerti. Tetapi, biasanya low-level languages tuh lebih efisien untuk mesin, lebih cepet, dan dependent on hardware (karena kasarnya mesin makin ngerti). Ya tapi bakal makin susah untuk di debug dan dimengerti![[Screenshot 2025-07-10 at 18.18.18.png]]

## Aspek lain dalam Pemrograman
- Source code = Kode atau di balik sebuah program yang ada.
- Editor dalam source code =
	- Text Editor
	- Visual Programming
- Pemroses Bahasa = 
	- Compiler = **Penerjemah**, tapi kalo compiler itu dia nerjemahin **seluruh** kode **sekaligus**. Contoh Pascal, C, dll.
	- Interpreter = **Penerjemah**, tapi kalo interpreter itu nerjemahin kode **baris per baris**. Contoh Python, Haskell, dll.
