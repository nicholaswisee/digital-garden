# README

Welcome to the Collaborative Notes page. To contribute, please refer to the following steps.

## Contributing

1. Contribute to the following [repository](https://github.com/nicholaswisee/digital-garden).
2. Create a branch from v4 and name it with the following format: name/course code (the one you want to edit), ex. Budi/IF1210
3. Open the "content" folder in Obsidian, and then create a new page based on a topic in the "Topics" Folder.
4. Once you're done editing that topic, don't forget to list that topic under the corresponding course code. 
5. Make sure to commit with clear descriptions! Whether you enter notes in md, put in links, etc.
6. Make pull requests, but please don't merge them immediately to avoid incompatibility. 

If you wish to contribute to the styling of this website, you are free to do so! Just make sure not to break anything.

## How Does This Work?

This website is built using Quartz, a static-site generator that turns content in markdown format into a webpage. By utilizing Obsidian as a tool for writing notes, we are able to build a website that displays your notes in this webpage.
